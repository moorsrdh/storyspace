**Project Title**
    StorySpace
**Project Option**
    Website
**Project Description**
    StorySpace is a website that showcases different locations and worlds from popular fantasy book series. The target audience is fantasy book lovers. The main goal is to allow users to explore different locations within these fictional worlds while discovering new books to read. The website features interactive pages with expandable book locations, information about each world, and a random book recommendation generator.
**Theme Interpretation**
    The theme is space, interpreted as the unique worlds and locations found within fantasy books. \
**Intended User or Player**
    Fantasy book readers who enjoy exploring fictional worlds and discovering new series.
**User or Player Goal**
    The goal is for users to learn about the different locations within fantasy books, explore their worlds, and receive recommendations for new books to read.
**Main Features**
    •	 Navigation links to different sections of the page
    •	Header with featured content
    •	Three main book sections
        o	Expandable menu for book locations
        o	Secondary expandable menu with additional information about each location
    •	Random book recommendation button
    •	Footer
**JavaScript Features**
    •	Expandable dropdown menus
    •	Nested dropdown menu for location details
    •	Random book recommendation generator
**Responsive Design**
    •	Layout stacks vertically on smaller screens
    •	Images resize to fit different screen sizes
    •	Navigation adjusts for mobile devices
**User Testing**
    Three users tested the website. They were able to navigate the site easily and enjoyed the content. The main issue discovered during testing was that the layout did not display correctly on mobile devices.
**Revisions**
    After user testing, the following changes were made:
      •	Improved the mobile layout so content displays correctly on smaller screens.
      •	Increased spacing between content boxes to improve readability.
      •	Adjusted image sizing and text alignment for a cleaner appearance across different screen sizes.
